## 📦 Installazione

Segui questi passaggi in ordine sulla Windows PowerShell del tuo PC o sul terminale:

### 1. Scarica la cartella di 18k bot
```bash
git clone https://github.com
cd 18kbot
```

### 2. Installa le librerie mancanti
I moduli pesanti non sono inclusi su GitHub per mantenere il progetto leggero. Installali digitando:
```bash
npm install
```

### 3. Avvia il bot
```bash
node .
```
Inquadra il codice QR che apparirà sul monitor con il tuo WhatsApp (da *Dispositivi Collegati*) e **18k bot** sarà subito attivo!

## 🔐 Sicurezza e Privacy
La sicurezza dei tuoi dati è garantita al 100%. I file sensibili delle sessioni (`auth_info_baileys`) e i file multimediali temporanei accumulati durante i comandi musicali sono stati inseriti nel file `.gitignore`. Questo assicura che le tue informazioni private rimangano sul tuo dispositivo e non vengano mai condivise pubblicamente su GitHub.
